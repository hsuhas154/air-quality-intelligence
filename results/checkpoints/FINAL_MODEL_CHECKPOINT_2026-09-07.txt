2. FORECASTING TARGET
================================================================================

Target:
  target_aqi_next_hour

Definition:
  AQI at the exact next hourly timestamp for the same city.

Auxiliary target used during model development:
  aqi_change

Definition:
  next-hour AQI minus current-hour AQI.

Modeling approach:
  Random Forest predicts AQI change, which is then reconstructed into the
  next-hour AQI forecast.

Conceptually:

  predicted_aqi_change = RF(features)

  predicted_next_hour_aqi =
      current_hour_aqi + predicted_aqi_change

7. IMPORTANT FEATURE-ENGINEERING METHODOLOGY
================================================================================

Lag features use exact timestamp matching.

A lag feature means:

  pollutant value exactly N hours before the prediction timestamp.

Missing exact timestamps remain missing.

The lag implementation does NOT rely on blindly shifting dataframe rows.

This protects against irregular timestamp spacing and prevents accidental
temporal misalignment.

The next-hour target is also constructed using exact timestamp lookup.

The target is NOT created using a simple shift(-1) across rows.

Therefore, a missing next-hour observation does not cause a later observation
to become the target incorrectly.


================================================================================
8. AQI COVERAGE GATE
================================================================================

Hourly AQI calculations use a PM2.5 station-coverage gate.

Minimum PM2.5 station coverage:

  Bengaluru: >= 5 stations
  Delhi:     >= 31 stations

A boolean feature is retained:

  pm25_coverage_valid

Station-count features are also retained for modeling.

This was introduced because early hourly AQI calculations could otherwise
produce artificial AQI jumps from extremely sparse station coverage.

================================================================================
17. IMPORTANT AQI METHODOLOGY CAVEAT
================================================================================

The current hourly AQI implementation is a CPCB-style approximation.

CPCB pollutant averaging periods include:

  PM10, PM2.5, NO2, SO2, NH3, Pb:
    24-hour averaging

  CO, O3:
    8-hour averaging

The current hourly feature pipeline does not yet fully construct all of
these prescribed averaging windows before calculating the AQI.

Therefore:

  The current forecasting result should be described accurately as being
  based on the project's current hourly AQI implementation.

Future production hardening should address the official pollutant-specific
averaging periods before presenting the platform as a fully standards-faithful
AQI implementation.
